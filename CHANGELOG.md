# Changelog

## 3.0.0 — 2026-10-05

### Added
- Qt 6 + QML desktop interface.
- Local video selection and drag-and-drop.
- Manual frame selection and horizontal score reconstruction.
- Per-join overlap adjustment with automatic estimation.
- Manual page cuts with visual editing.
- A4-focused PDF pagination and preview workflow.
- Background processing and progress logging.

### Changed
- English UI and English project documentation.
- Simplified processing pipeline focused on cropping, reconstruction, layout, and PDF export.
- Removed unused motion-tracking and moving-overlay removal features.
- Removed administrator-only launch scripts and permission workarounds.

### Fixed
- Stable seam-list scrolling while editing multiple joins.
- Horizontal preview scaling and navigation.
- Preview/PDF export path handling.
- QML file URL handling.
- Horizontal A4 pagination.
